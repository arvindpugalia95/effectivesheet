🔧 Google Sheets Setup Instructions

  1. Create a new Google Sheet
  2. The app will automatically create separate sheets for each client when you add them
  3. Each client sheet will have headers: DATE | Client Name | Project | Activity | Clockify Hours | Effective Hours | Recurring/Adhoc | User | Timestamp
  4. Go to Extensions > Apps Script
  5. Paste the provided Apps Script code (see below)
  6. Deploy as Web App (Execute as: Me, Access: Anyone)
  7. Copy the Web App URL and paste it in js/config.js

📋 Apps Script Code

Make sure you've copied the code from the apps-script-code.gs file into your Google Apps Script editor, saved it, and deployed it with "Who has access" set to "Anyone".
